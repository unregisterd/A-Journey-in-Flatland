# A Journey in Flatland
平面国游记
Flatland Travelogue — a 2D Unity game inspired by the novel Flatland.
游戏类型：2D横版跳跃  动作解密
故事简介：三维世界的立方体阴差阳错地进入平面国后变成“贱民”正方形，体会平面国风土人情的冒险故事。
（2026/4/7）开发日志-1
《平面国游记》的制作到目前进展不大，第二关已接近尾声，许多细节有待完善。文本的UI交互：触碰记忆球后吸收并且展示对话框或者文本、关卡引导提示···关于游戏的菜单界面一点都没有构思呢。但是玩家状态机和技能部分已经足够完善，接下来要做的是“招聘”美术，设计接下来的关卡和剧情。
第一关玩家通过“平衡台阶”进入下一关，通过“节奏台阶”获取记忆球，这两部分是相互独立的，关于这一点我很纠结，因为这样的设计让许多玩家会选择直接通关的道路而不是去获取记忆球，第一关的剧情是正方体得罪了六边形从而被打入牢房，衔接第二关逃出监狱的剧情。目前来看我想不出有什么好的办法让第一关更加精彩了，那么就这样吧，如果想要了解故事的话就挑战难度，想要直接通关那么直接走简单的台阶。不过后续关卡也会出现“节奏台阶”。
第三关的初步构想是梦魇。就在正方体即将逃出监狱之际晕倒，然后陷入梦境。剧情这个时候开始到达高潮，也要开始真正的将玩法和技能相结合了。
（2026/4/8）开发日志-2
  思来想去，还是一个人完成这部作品，因为毕竟这只是我第一次做游戏嘛，如果要与人合作的话，必然需要交流沟通、精心打磨，况且招不招的到人还要另说了。
  今天总算添加了记忆球的功能：漂浮、触碰到玩家后消失、显示文字。但是出现了中文显示的问题，由于短时间内无法解决，暂且搁置。还有文本的展示面板我需要好好考虑一下美术的问题，总不能做得太粗糙吧。
  第二关终于收尾了，虽然很仓促，但还是结束了。
（2026/4/15）开发日志-3
  这几天完善了一二关的新手引导功能，想起来还是有些小瑕疵，但问题不大，以后可以慢慢添加和修改。今天一整天都在进行第三关（梦魇）Part1的制作，第三关整体来说剧情展开并不多，毕竟这只是正方体的三层梦境，但确实展现了更深层面的东西。
  第三关Part1，主题是“逆行”，及与玩家正方体交互的绝大多数平台都与玩家的方向相反。主要体现的思想：“世界与我背道而驰，但这些都将成为我的助力。”
  拼凑出一颗完满的心，有时也会离开。一半追逐着另一半，但并不总是如此。
  拼凑出一张完美的笑脸，有时也会哭泣。一半追逐着另一半，但并不总是如此。
  拼凑出一个完整的对勾，有时也会错误。一半追逐着另一半，但并不总是如此。
  以上是这一关前三分之一需要展现的思想，希望效果能够达到预期吧。关于机制和技能结合的部分我尽力去做了，也为正方体技能专门定制了解谜环节。但我逐渐发现《平面国游记》正逐渐靠向纯粹的平台跳跃游戏，也许是因为解谜确实很考验游戏制作者的脑力和功底，而我现在还需要绞尽脑汁去想这些解谜环节着实有些难为。但我会尽力在后续关卡中补足解谜环节，适当弱化动作部分（手残党何苦为难手残党）。
  第三关Part2，主题是“悬浮”，与玩家正方体交互的绝大多数平台都是悬浮的。主要体现的思想：“浮动是我的心绪。”
  由于Part1占比太大，并且有些一发不可收拾，所以我决定将Part2做得短小精悍一点（嗯，大概）。

（2026/4/16）开发日志-4
  今天想起来一二关还需要完善的内容，然后框框修改补充了一波，总算是能玩了。第三关也正在有力推进，Part1和Part2已经基本完成，Part2悬浮场景考验玩家的反应力和观察力，解谜部分也十分简单，但操作起来很是不容易（至少我会死很多次）。
  第三关Part3，主题是“分裂”，视野中会有很多玩家“正方体”。主要体现的思想：“究竟哪一个才是真正的我。”玩法还没有真正想好。
  
  在第三关首次添加了检查点（前两关太容易所以没有必要，），因为第三关地图扩充，难度确实有点大，一不小心就会死，死亡过后回到原来的位置，之前好不容易通过的地方却还要再次经历这样的痛苦······总之我是深有体会。
  咳咳，总而言之呢《平面国游记》的定位是2D的横版跳跃、动作、解谜游戏，不是那种超级硬核的需要玩家一直死磕的游戏。
  还是决定招人了，嗯，招美术。目前没有任何水花，难道我注定要一个人做游戏吗？

（2026/5/14）开发日志-5
  嗯······游戏已经制作完成了，至于中途不写开发日志的原因是意识到游戏做出来的效果可能不如预期，但是没有关系，尽量完成就好了。
而且，你看，《平面国游记》一共五个关卡，刚好开发日志也只有五篇。
最后还是没有找到人一起合作捏。
说说4、5关吧，第四关我首次接触到渲染管线的概念，在游戏中引入光照，想要达到明暗交替的效果，第四关是接近尾声的环节，也是正方体走出噩梦（第三关）的过渡关卡，主题是：错过。
一场小小的邂逅，将视角聚焦于平面国的边缘人群：线段。
小有遗憾，但是美好。
  首次加入粒子效果：模拟花瓣纷飞和细小尘埃以及萤火虫的飞舞。
  值得一提的是玩法加入光线解谜，用2D光引导玩家利用激光的反射效果，解开机关门。
  第4关的通关条件是找到两个春天的象征：蒲公英和萤火虫，本来还有一个“雨夜漫步”，但是概念有些抽象，而且想不出更多的创新点，遂作罢。
  第五关的主题：告别。
没有引入新的机制和玩法，不对，有一个类似“下楼梯”的小环节，源自我学会的第一个游戏，里面的代码直接迁移改编一下也能用。还有第五关的相机并不跟随玩家，而是固定在一个位置，因为我想尽量精简，尽快完成游戏。整体来说第5关基本延续之前的内容，没有过多的创新了。最后我在商城里找了免费素材为游戏添加了GUI界面以及音乐。
那么《平面国游记》就告一段落了。我不喜欢道别，也不擅长。所以这次只是总结。在《平面国游记》当中我收获良多，了解到了GUI、代码逻辑、音频、特效相关知识。我相信学到这些知识可以帮助我走得更远。
